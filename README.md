# Simple Interest Calculator

## Description
This project is a simple interest calculator written in Bash. It calculates the interest earned on a principal amount based on the annual interest rate and time period.

## Features
- Accepts the principal amount from the user.
- Accepts the annual interest rate.
- Accepts the time period in years.
- Calculates and displays the simple interest.

## Formula
Simple Interest = (Principal * Rate * Time) / 100

## How to Run
1. Clone the GitHub repository.
2. Open a terminal in the project directory.
3. Make sure Bash and bc are installed.
4. Run `bash simple-interest.sh`.
5. Enter the principal amount, interest rate, and time period.

## Example
Principal: 1000
Rate: 5
Time: 2

Output: Simple Interest: 100.00

## Requirements
- Bash
- bc utility
